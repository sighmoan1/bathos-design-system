Typography and space

Aptos, Segoe UI, Helvetica Neue and Arial keep the system local. Body text uses a 1.6 line height and a 65-character measure. Controls have at least a 44px target.

Spacing: 4, 8, 12, 16, 24, 32, 48, 64 and 96px. Radius: 4, 10 and 16px.

Set a palette for a site

Each site keeps its own bathos-design-system.json beside its app code. Change the palette there; the site's next build applies it. You don't need to change this shared repository to switch another site's design.

This control previews a palette across the whole catalogue in your current browser session. It does not change or deploy a site's setting.

Use the shared package

Install a specific release and commit the lockfile. Styles are bundled locally at build time, so a catalogue outage cannot affect a site.

npm install @bathos/design-system@https://github.com/sighmoan1/bathos-design-system/releases/download/v{{version}}/bathos-design-system-{{version}}.tgz
import '@bathos/design-system/styles/tokens.css';
import '@bathos/design-system/styles/base.css';
import '@bathos/design-system/styles/components.css';
import '@bathos/design-system/styles/palettes.css';
import { Button, Field } from '@bathos/design-system';

// Set on the app root at build time:
<html data-bathos-palette="deep-water-red">

Existing themes can import foundation.css and palettes.css for namespaced --bathos-* values and set the same document-root attribute. Keep service-specific layouts and interaction behaviour in each app.

Release and propagation

Patch releases fix defects; minor releases add compatible features; major releases require deliberate migration. Each site pins the package version and palette in its own repository. Builds use those exact settings and deploy through the site's release path.

Keep the previous package version and deployment available for rollback. No production page loads a floating latest version or remote stylesheet at runtime.

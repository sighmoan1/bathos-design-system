Colour and type

Keep most surfaces neutral. Use wine for actions, ocean for information and lavender for selection. Always pair colour with text or shape.

Typography and space

Aptos, Segoe UI, Helvetica Neue and Arial keep the system local. Body text uses a 1.6 line height and a 65-character measure. Controls have at least a 44px target.

Spacing: 4, 8, 12, 16, 24, 32, 48, 64 and 96px. Radius: 4, 10 and 16px.

Use the shared package

Install a specific release and commit the lockfile. Styles are bundled locally at build time, so a catalogue outage cannot affect a site.

npm install @bathos/design-system@https://github.com/sighmoan1/bathos-design-system/releases/download/v{{version}}/bathos-design-system-{{version}}.tgz
import '@bathos/design-system/styles/tokens.css';
import '@bathos/design-system/styles/base.css';
import '@bathos/design-system/styles/components.css';
import { Button, Field } from '@bathos/design-system';

Existing themes can import foundation.css for namespaced --bathos-* tokens and map only the values their service needs. The dark reader and GOV.UK simulators retain their layout and interaction contracts.

Release and propagation

Patch releases fix defects; minor releases add compatible features; major releases require deliberate migration. Stable releases produce package archives, then each consumer checks for updates and opens a version-pinned pull request. Builds and browser checks run before adoption.

Keep the previous package version and deployment available for rollback. Automatic updates never replace a consumer's production stylesheet at runtime.
